Estruturas básicas do JAVASCRIPT

O JavaScript possui diversas estruturas que ajudam a controlar o funcionamento de um programa. Entre eles estão estruturas de decisão, repetição e organização de dados.

O switch é usado quando você precisa comparar uma mesma variável com vários valores possíveis (opções). Em vez de escrever vários "if/else" seguidos, você usa "case" pra cada valor esperado. Se nenhum caso bater, o "default" entra em ação.

O for é uma estrutura de repetição usada quando você já sabe quantas vezes quer repetir algo. Ele tem 3 partes: onde começa, até onde vai, e o quanto avança a cada volta. Muito usado pra percorrer listas e vetores.

O while repete um bloco de código enquanto uma condição for verdadeira. Diferente do "for", você não sabe de antemão quantas vezes vai repetir — ele para assim que a condição vira falsa.

O do while funciona parecido com o "while", mas com uma diferença importante: ele executa o código primeiro e só depois checa a condição. Isso garante que o bloco rode pelo menos uma vez, mesmo que a condição já comece falsa.

O vetor (ou array) é uma estrutura que guarda vários valores em uma única variável, organizados em posições numeradas a partir do zero. É útil quando você precisa armazenar uma lista de itens, como nomes ou números.

A matriz é como um "vetor de vetores" — uma tabela com linhas e colunas. Cada posição é acessada por dois índices (linha e coluna), sendo muito usada pra representar dados em formato de grade, como um tabuleiro.
